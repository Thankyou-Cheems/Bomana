# Keep Paid-Feature Preview in the External Website

Status: Accepted (2026-08-03)

The Launcher exposes a Website Preview Entry that opens
`https://bomana.ruikang.wang` in the user's external browser. It is available
to all editions, including users without an Entitlement and Standalone Green
Lite. The Launcher does not embed the site, perform a payment or entitlement
check for the preview, or make application startup depend on the page.

This keeps promotion and CheemsPay account interaction in the website while
the Launcher remains a local orchestrator.
