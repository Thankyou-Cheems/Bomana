# Public Editions Contract

- `PUB-01`: Lite MUST expose only the respawn-cycle timer and timer settings.
- `PUB-02`: Standard MAY add flight status, fuel, checklist, and navigation to official zones and airfields.
- `PUB-03`: Standard MUST NOT expose manual POI, Trace back, hostile targets, grid coordinates, chat recognition, countdowns, airport modules, Y66, terrain elevation, or weapon solving.
- `PUB-04`: Public telemetry MUST NOT request gamechat, terrain, mobile pairing, or an Enhanced route.
- `PUB-05`: Public builds MUST include only Lite and Standard App artifacts.
- `PUB-06`: The public Launcher MAY link to Enhanced but MUST NOT contain Enhanced implementation or artifacts.
