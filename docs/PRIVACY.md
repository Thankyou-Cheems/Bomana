# Privacy

Bridge keeps official 8111 traffic on the local machine. It does not upload game telemetry, target positions, selected weapons, terrain, or calculations.

The Online Launcher contacts Bomana's public site for version metadata and may contact CheemsPay only when the user chooses Enhanced authorization. Lite and Standard do not require a CheemsPay account.

Any anonymous daily-active signal is Web-owned, contains no account or gameplay data, and is documented before enablement.
