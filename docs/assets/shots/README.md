# 实机截图占位说明

页面「实机界面」区块会优先加载下列文件名。把截图按名称放到本目录后刷新站点即可（无需改 HTML）。

| 文件名 | 建议内容 | 建议比例 |
|--------|----------|----------|
| `desktop-main.png` | 主窗口（计时 + 仪表） | 16:10 或 4:3 |
| `nav-hud.png` | 导航 / HUD 叠加层 | 16:9 |
| `web-cockpit.png` | 手机或浏览器网页驾驶舱 | 9:16 或 16:9 |
| `launcher.png` | 启动器界面 | 16:10 或 4:3 |

推荐 PNG（透明边亦可），长边约 1600–2400px。未上传时页面显示设计好的空位，不会 404 破版。
