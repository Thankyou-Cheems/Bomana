# Public Site Screenshots

This directory contains public Lite/Standard and universal Launcher screenshots
used by the documentation site.

| File | Surface |
|---|---|
| `desktop-main.png` | Standard main window |
| `nav-hud.png` | Standard navigation strip |
| `nav-precision.png` | Standard navigation detail |
| `launcher.png` | Universal Launcher |

Subscriber implementation screenshots belong to the private release and are
not generated from this repository. Before replacing an image, capture the
current packaged artifact at a representative Windows scale and verify the
site at desktop and narrow widths.
