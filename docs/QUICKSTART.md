# Quick Start

1. Open <https://bomana.ruikang.wang/launcher/>.
2. Download and run Bomana Bridge from the Launcher.
3. Return to the Launcher and click retry if Bridge was not detected automatically.
4. Select Lite for timer-only use, or Standard for Basic Navigation.

No Python installation and no desktop Launcher are required.

Bridge reads only official local 8111 routes. It does not read process memory, inject code, modify game files, or synthesize game input.
