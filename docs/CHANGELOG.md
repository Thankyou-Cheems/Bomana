# 更新日志 | Changelog

所有重要的项目变更都会记录在此文件中。

本项目遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

---
## [6.13.0] - 2026-03-23

### 修复
- 修复计时器在部分用户环境中偶发卡住、切出游戏后恢复的主线程竞争问题
- 将 `GameLogic.snapshot()` 调整为“锁内采样、锁外派生”，降低 UI 刷新与 tick 线程的锁争用

### 改进
- 将起落架进度消抖稳定逻辑固定在 tick 线程，避免 UI 快照路径写共享状态
- 调试诊断改为结构化 `perf/source/clog` 字段，区分锁等待、锁持有、8111 数据状态和 UI 帧间隔
- 新增计时器卡顿排查指标，便于后续在全屏/无边框实战中快速定位问题来源

## [6.8.0] - 2026-02-12

### 新增
- 新增 HUD 全屏叠加层主目标渲染（2.5D/2D 自动降级）
- 新增姿态可信度链路（缺失/恒零/抖动检测）并输出 HUD fallback 标记
- 新增 HUD 顶部简化罗盘条（航向 + 目标偏移）
- 新增 HUD 设置与持久化：开关、透明度、缩放、平滑、显示器策略（主窗口/鼠标）、配色、罗盘开关

### 改进
- HUD 生命周期接入主 UI 刷新链路与全局热键（F12）
- 增强 HUD 降级守护：短时 8111 抖动保留最后有效目标，断连待机提示更稳定
- 将手工评估脚本流程移除，回归直接游戏内实测流程

### 合规说明
- HUD 仍仅使用官方 `localhost:8111` 数据源
- 不引入敌方标记、内存读取、注入或游戏文件修改能力

## [6.7.0] - 2026-02-06

### 新增
- 新增绿色版通用启动器 `launcher.pyw`（发布名：`Bomana_launcher_v*.exe`）
- 启动器每次启动自动检查更新（优先国内更新服务，失败或仅版本检测场景自动回退 GitHub）
- 新增可替换应用包发布形态：`Bomana_app_<Variant>_vX.Y.Z.zip`
- 新增发布清单 `manifest_<Variant>.json`（版本、包名、SHA256）
- 启动器新增“详情/支持作者”弹窗入口（复用主程序赞助资源）

### 改进
- 新增 `tools/build_portable.py` 与 `tools/scripts/build_portable.bat`，统一构建 Launcher + app.zip + manifest
- GitHub Actions 发布流程切换为绿色版产物链路
- CI 拆分为 `build_app` 与 `build_launcher` 两类产物构建，支持手动选择构建目标（all/app/launcher）及标签选择目标（`vX.Y.Z` / `vX.Y.Z-app` / `vX.Y.Z-launcher`）
- 启动器升级为可视化引导界面：自动检查、来源展示、下载总大小提示、下载二次确认、离线启动/重新检查/打开下载页等完整交互
- 启动器下载状态反馈增强：显示进度百分比、传输速度，完成后明确提示安装位置
- 启动器界面缩放与字体渲染优化（DPI 感知 + 主程序同优先级字体策略）
- 修复进度条与动画误导问题（检查阶段不假满、完成后状态符号稳定）
- 打包脚本为启动器补充运行时资源（`app.ico`、`sponsor_wechat.png`）

## [5.9] - 2026-01-12

### 新增
- **燃油管理系统**（v5.8 基础上完善）
  - 油量监控：显示当前油量（kg）和百分比
  - 油耗率计算：基于 60 秒采样窗口（使用 deque 优化性能）
  - 剩余飞行时间估算
  - 返航油量估算：三级警告系统（充足/注意/不足）
  - 高度显示：实时飞行高度
  - 智能补给检测：油量突增自动重置采样
- **窗口吸附优化**
  - 多显示器支持：自动识别窗口所在显示器
  - 智能边缘吸附：可配置吸附距离（默认 20px）
  - 边界检查：确保窗口不超出可见区域

### 改进
- **战区目标选择算法优化**
  - 角度优先于距离：在 45° 角度门内选择角度最小的目标（而非距离最近）
  - 目标粘性改进：90° 内保持锁定，避免频繁切换
  - 精确对准确认时间调整为 3 秒
- **UI 性能优化**
  - 使用 Grid 布局替代 Pack，确保面板顺序固定
  - Label 复用池：避免频繁创建/销毁 UI 组件
  - 字体缓存：预计算所有字体元组
  - 智能刷新：仅在数量变化时重算窗口尺寸
- **底部提示文字宽度优化**
  - 增加 hint_min_width 确保快捷键提示完整显示
  - 修复多显示器环境下提示文字可能被截断的问题

### 修复
- 修复面板开关时窗口尺寸计算不准确的问题
- 修复多显示器环境下窗口位置恢复错误
- 修复燃油采样在低速时累积过多数据的问题
