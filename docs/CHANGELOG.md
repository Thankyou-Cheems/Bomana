# 更新日志 | Changelog

所有重要的项目变更都会记录在此文件中。

本项目遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [8.7.18] - 2026-08-23

### 改进
- 数量计算器改为大厅同一套溅射公式自动计算，不再使用 gameparams「1 kg TNT = 8 HP」，
  也不再手抄每条武器的大厅数字。输入是炸弹 BLK 的装药/炸药类型/燃烧弹 splash/核弹
  yield，加上 `explosive.blkx` 曲线和 `bombing_zone` 装甲参数。
- 高阶空战战区：Mk 83 满额摧毁 6 枚 / 触发燃烧 5 枚；10×Mk 82（1175.85 kg TNT）可点燃；
  2×GBU-31 + 1×GBU-39 刚好低于 90% 燃烧线，再补一枚 GBU-39 才够。
- 燃烧弹、穿深不足 25 mm 的火箭、核弹纳入同一公式；机场模块回血仍按生活区 visit
  脚本。大厅收益系数按 `BombingRewardMultipliers` 从总伤害自动得出。
- 在线计算器改成大厅风格：大数字显示摧毁/点燃枚数，收益系数一并给出；调试字段收到「计算说明」里。

### 兼容性
- 武器目录仍只保存输入参数；溅射曲线单独锁哈希。版本更新后若只改炸弹字段，重跑
  提取器即可，不必返工手表。
- `v8.7.17-app` 保持已发布制品不变。

- `v8.7.15-app` 保持已发布制品不变。

  仍不含 CCRP、投弹解算或网页驾驶舱。
- Mk 77 等 napalm 不走 TNT 当量公式，计算器明确标为原生未知。
- `v8.7.14-app` 保持已发布制品不变；本次使用新版本 8.7.15。

## [8.7.14] - 2026-08-21

- 三个版本均新增可独立打开的“打击百科”，可从主窗或托盘进入；超级爆弹版还可从
  CCRP 卡片直接打开。百科集中展示 EC 机场结构、六档战区/机场任务耐久以及版本
  锁定的炸弹装药参考。

  不提供未经证实的 HP→TNT 换算，Mk 77 等燃烧弹也不会伪造 TNT 当量。

### 兼容性
- `v8.7.13-app` 在发布前格式检查阶段停止，未生成、发布或部署任何 App 制品；修复版
  使用新版本 8.7.14，不移动或复用失败标签。
- 百科数据与实现进入 Enhanced、Standard、Lite 三种 App 包；Standard/Lite 仍不包含
  CCRP、投弹解算、武器物理目录、网页驾驶舱或 Enhanced 地形资源。
- 运行时只读取随 App 发布的静态目录，不启动、附加或读取游戏进程；实时目标链仍只
  使用官方 8111 数据和离线地形。

## [8.7.6] - 2026-08-14

### 改进
- 超级爆弹版新增 EC 机场模块目标：仅在完整敌方 8111 跑道端点、已匹配的离线
  地形地图和内置静态目录能唯一对应时，才可选择跑道、油库/仓储、停机区或生活区
  作为 CCRP、滑翔或卫星制导炸弹的共同目标；端点缺失、地图不匹配或歧义会严格
  停止，不再把机场中心、战区或 POI 当作替代。该目录覆盖 48 个 EC 布局、16 个
  terrain map ID 与 4 种模块几何，纠正了“现代/二战只有两种机场”的假设；它不是
  服务器 hitbox 或原生游戏命中等价声明。
- 高阻炸弹 CCRP 现在按哈希绑定的离线客户端公式逐步计算制动展开：时间与高度
  因子取最大值，再把 `brakeCxK` 与 `brakeArm` 分别加入轴向阻力和稳定器力臂；
  移除了旧的经验倍率与错误的速度窗口解释。
- 滑翔及 INS/GNSS 制导炸弹在静态物理与目标环境完整时，使用 `1/48 s` 的独立
  可达集积分计算条件化最小/最大投放距离；界面明确标记为实验模型，不声称闭源
  PN/loft/PID 自动驾驶原生等价。冷包线计算由单一 latest-wins 后台任务完成，
  不再阻塞 8111 轮询，过期分箱结果也不会继续显示；缺失 TAS/目标高程基准或
  物理扫掠无交点时严格失败关闭，不会降级显示旧经验包线。
- 飞机 IAS/Mach 限速、离线刚体和武器目录统一刷新到 Datamine `2.57.1.89` /
  `9f8cdbc99342`。本次飞机限值与 437 条炸弹参数没有数值变化；F-14A Early 的
  挂载兼容关系由 AIM-9D/G 更新为 AIM-9L，并同步槽位引用。生成时间改取来源提交
  时间，同一提交重复提取的三个静态资产现可逐字节复现。
- 离线刚体目录升级到 schema 3，锁定 Datamine `2.57.1.89` / `9f8cdbc99342`，
  保留 24 条制动参数与 81 条制导自动驾驶参数；生产运行时仍不读取游戏进程内存。
- Enhanced 继续以字节码包发布，并通过 CheemsPay 私有制品网关向 Launcher 3.5.6
  下发；清单要求 Launcher >= 3.4.0，并使用统一发布签名根验证。
- `v8.7.5-app` 在发布前 Ruff 门禁失败，未生成 Release 或生产制品；该版本号不复用，
  修复后的正式候选顺延为 8.7.6。

## [8.6.2] - 2026-07-25

### 改进
- 超级爆弹版网页驾驶舱按 SiguaArmor 的近黑、暖米金和细边框视觉语言重构为任务工作台：桌面与手机继续以地图为主，飞行读数、武器/CCRP、导航、告警、快捷操作和配对页统一为更紧凑的分层信息架构。
- 超级爆弹版升级深度学习的高精度打击模型与地形数据，改善不同弹药、飞行姿态和起伏地形下的 CCRP 提示一致性。
- 网页地图新增美观的地形晕渲，可与战术底图和矢量标记叠加，并支持独立开关与强度调节。
- 航向带把偏航、精确捕获和目标距离合并进本体：主刻度继续保留战区、POI、坠毁点与友/敌机场，底部非线性精确区用捕获门和平滑游标放大小角度偏差，不再额外占用两行左对齐状态。
- 集成导航面板移除航向带下方重复的目标图例与“精细航线”文字提示，只保留航向带本体内的目标标记、精确游标、捕获门和距离信息，进一步压缩垂直占用。
- CCRP 卡片进一步压缩：目标与数字高程移入标题行，已知高程在窄宽度下优先保留，默认释放条由 52 px 缩至 42 px；解算时间轴、释放窗口和抗抖状态机保持不变。
- 介绍站 canonical 入口迁移到 `bomana.ruikang.wang`，浏览器版本卡片改为优先读取同源部署目录；Launcher 的 App、自更新和地形服务继续固定使用独立的 `bomanaupdate.ruikang.wang`，旧 `/bomana` 路径按迁移指南保留逐路径永久跳转。
- 启动器继续独立维护地形数据：普通 App 更新不重复携带未变化地图，地形变化时只下载必要内容。
- 发布包、更新清单与下载文件增加更严格的完整性和大小校验，降低损坏或异常更新造成的启动失败。
- 网页战术地图新增桌面端 `Alt + 左键` 自定 POI：点击坐标经过当前跟随/平移/缩放的精确反投影后立即进入 App 快照，并复用既有 POI 导航、数字高程与 CCRP 链路。POI 模式会暂停战区自动选取，手动点不再因战区销毁或列表变化失效，且偏离当前航向时仍保持为明确目标；新的 8111 原生 POI 依然立即优先并触发短暂弱提示，全程不写游戏或增加游戏接口。
- 完整六键热键配置已正确注册；发布流程同时生成签名清单、校验文件和来源证明。

## [8.6.0] - 2026-07-24

### 改进
- 完全移除实验性桌面全屏 HUD：删除透明投影窗口、设置页入口、运行时生命周期、专用姿态降级字段与采样工具；旧 `hud_enabled` / `hud` 配置会在迁移或下次保存时清理。独立导航栏、CCRP 提示栏与 Web Cockpit 不受影响。
- 超级爆弹版移除名称中的警示后缀；启动器新增独立离线地图包状态卡，显示已安装/最新/差量可更新/待安装/需修复/旧包可迁移及地图数量、修订号和体积。“启动与版本”栏与状态栏按窗口宽度动态伸缩，内部文本按实际栏宽重排。
- 重构超级爆弹版 `CCRP`：同一组件可在主窗集成显示或独立显示；当导航栏也独立时自动挂载到导航栏下方。集成标题与机场/燃油标题对齐并沿用红色“关闭”操作，独立标题栏沿用独立导航风格，`✕` 仅返回集成模式。
- 弹药切换改为与速度阈值入口一致的蓝色文本框按钮，移除左右切换键；目标高程摘要不再重复显示数据来源，轨迹来源、距离和独立姿态恢复提示等冗余行全部收进 CCRP 指示条。
- CCRP 对称收束指示器改为追踪因果释放时刻，而非逐帧追逐带噪倒计时；通过死区、限幅修正、连续的 5 秒/0.5 秒映射和越点滞回消除跳变，释放窗闪绿，确认越点后显示红色越界线。
- 新增默认 `F6` 投弹目标来源快捷键和栏内实体按钮，显式在“战区 / 兴趣点”之间切换；解算链不再在目标重合或缺失时自动从一种来源回退到另一种来源。
- 生产运行时只消费官方 `127.0.0.1:8111`、离线高程包与内置静态模型；普通热键直接使用 Windows `RegisterHotKey`。
