## [Unreleased]

### 改进
- 网页驾驶舱改为全屏战术 HUD：地图铺满视口，琥珀色仪器浮层叠在态势上；手机底栏突出切换武器，控制台与图例收入浮层。
- 网页快照轮询提至约 20Hz（与 App UI 刷新对齐），地图与航向带优先重绘；官方地图底图后台刷新由 15s 收紧至 2s。
- 合并底栏重复的操作/控制台入口为单一「设置」；重做主按钮样式；增加超速提示条；统一武器解算与导航面板配色。
- 去掉重复的切换武器/图例入口；地图默认跟随并以武器射程、目标距离与近距接触自动缩放。
- 本机 Web 控制会话可在设置 → 网络中开启/关闭局域网访问与控制，并显示可复制的手机访问链接；仅 loopback 可执行该命令。
- 局域网开启后提供本地生成的配对二维码，手机扫码即可打开带配对码的访问链接。
- 配对二维码改用标准库生成（ECC-M、≥4 模块静区、纯黑白模块），提高 iOS 相机等严格扫码器的识别率。
- 常用操作外置到底栏：重置计时、切换角落、局域网开关/接入；设置仅保留状态、显示与武器策略。
- 手机端左侧读数默认折叠为紧凑条，缩放控件移到右下角，减少对战术地图的遮挡。
- 手机端展开读数时地图舞台右移并重绘，保证展开状态下态势仍可用。

## [8.2.0] - 2026-07-12

### 新增
- 计时周期现在可在 1–180 分钟内配置，并通过托盘和网页控制台使用同一显式目标；活动出击保留出生时间并立即按新周期重算，持久化恢复会拒绝周期不匹配。
- 计时进度改为倒计时右侧的香蕉剪影描边，速度条从首个阈值 70% 起连续放大三段解体速度标记。

### 改进
- Launcher 3.1.0 新增“启动时开启局域网访问与控制”偏好；选择它会同步启用 Web 自启动，关闭 Web 自启动会清除 LAN 偏好。Launcher 仍只保存三个布尔值，地址、端口、配对和实时授权由 App 每次运行重新生成。
- App 与托盘合并局域网访问/控制为一个动作；成功绑定自动发现的一个或多个 RFC1918 精确地址后才授予后续配对控制，关闭时立即撤销全部 LAN 会话。
- 压缩武器解算冗余来源文案，使用更明确的空战/返航术语，并以统一边框、指针和悬停反馈标出 App 可点击区域。

### 修复
- 修复窄窗口或较大文本缩放下，动态换行后的最低功能/武器卡被固定底栏遮挡的长期问题；现在只在实际请求高度增长时进行防抖扩展重算。
- 修复低速阶段速度条停止增长的问题，并在 LAN 控制授权失败时原子回收已建立的监听和 Host。

## [8.1.0] - 2026-07-11

### 新增
- 网页战术地图现在使用 App 后台从官方 loopback `/map.img` 获取的有界 PNG/JPEG 内存快照作为半透明底图，并按当前武器解算与地图比例动态叠加最小/最大射程椭圆；浏览器仍不访问或代理 8111。
- App 主窗口底部新增紧凑网页访问行，直接显示本次配对码、本机或全部局域网监听地址，并提供打开页面、开启/关闭 LAN、允许/撤销 LAN 控制的实体按钮。

### 改进
- 网页端统一使用项目 PNG 标识，压缩重置/角落和模型控制布局，将 15 分钟进度放到倒计时旁，并统一为“官方数据始终优先；缺失时是否使用推测替代”的跨端文案。
- App 武器解算只保留武器、目标、包线/窗口、时间和简短来源；燃油详情压为一条响应式摘要，速度条展开 65%–105% 临界区间，管理员热键提示改为短句。

### 修复
- 修复 LAN 开启后只绑定首个 RFC1918 地址，导致 Wi-Fi 与 EasyTier/虚拟私网不能同时访问的问题；现在会为每个可绑定的私网地址建立独立精确监听，并在关闭或撤销时统一回收。

## [8.0.0] - 2026-07-11

### 新增
- 新增 Bomana 网页驾驶舱：在独立端口提供响应式地图与计时、飞行、燃油、导航、武器/投弹、检查清单和告警面板；默认仅监听本机，托盘可为本次运行显式开启单个私有 IPv4 的手机访问。飞行展示只读取筛选后的 `UISnapshot`，不代理 8111、不发布敌机标记，也不依赖外部网页资源。
- 网页驾驶舱新增经过会话授权的实体控制：重置计时、切换窗口角落、显式设定锁定/提示音/战区提示音、显示或隐藏六类面板，以及在功能可用时选择当前武器和弹道模型。所有写入使用固定语义 allowlist，不模拟 F7-F11、不调用任意回调，也不扩展热键 Broker。
- 新增独立配对会话、同源 Origin、每会话 CSRF、有界幂等与异步完成协议。本机配对可控制；LAN 配对默认只读，只有本机为本次运行开启 LAN 控制并使用新配对码重新配对后才可操作，撤销立即使已有 LAN 控制会话失效。

### 改进
- 将源码版本边界提升为 App 8.0.0 / Launcher 3.0.0：打包 App 在任何运行时初始化前校验 Launcher 3 身份；Launcher 对启动、在线安装、本地导入、回退和异常恢复共用严格版本边界，在替换有效目录前拒绝无效或旧 App，并要求暂存包版本与已验签清单完全一致。发布清单 schema 与签名字段保持不变。
- 重做 Launcher 的 tkinter 信息层级与操作布局，保留通道、更新、代理回退、导入、回退和自更新能力；新增仅限本机 Web 服务自动启动与成功后自动打开页面的两个持久化偏好。端口、配对、LAN 访问及 LAN 控制仍全部由 App 在当前进程管理。
- 将 Enhanced 的“投弹预测”升级为紧凑武器解算：自由落体/高阻炸弹保留 CCRP，AAM/AGM 优先插值 Datamine 条件包线，无表滑翔武器可选择使用明确标为实验参考的推测替代；当前 8111 未证实所选挂载字段，因此继续采用按机型过滤的手动选择且不声称锁定、NEZ 或发射授权。
- 新增同一战局内的上次坠毁点 Trace back，复用经过消抖的玩家损失状态机；POI 改为游戏风格的红色开放四角标记，二者都复用现有集成/独立航向带而不新增地图窗口或主导航行。
- 统一主界面的可点击控件为常驻按钮心智，并为管理员游戏前台热键增加 F8 解锁说明与托盘直达入口；UAC 仍只在用户点击并二次确认后触发。
- 新增官方 8111 对局录制器：以同步 gzip JSONL 保存四个 loopback 端点的解码原始 payload、响应诊断和摘要，支持 `Ctrl+C` 安全收尾且默认写入被 Git 忽略的本地目录，为后续确定性快进回放提供真实格式基线。
- 新增确定性 8111 快进回放：完整校验录制流后以虚拟时钟和本地响应源驱动生产 `GameLogic`，支持最大速度或倍率播放，并用 `full-sortie` 配置检查大厅、两次起飞、着陆整备、投弹、周期跨越、临界超速与坠毁退出。
- 将首场 4281 帧真实完整航程录制按原始字节纳入测试库，以 schema 清单锁定来源/fixture SHA-256 和期望时间线；标准 pytest 与 CI 现在会自动回放这场 17 分 58 秒对局。
- 清理已完成的阶段性 UI 计划和重复测试，将 8111 回归迁为按核心边界命名的 pytest 测试，并新增文档集合与本地链接卫生门禁。
- 移除可变 Python App 包的整包提权路径；普通热键默认先启动，确认 War Thunder 普通运行时不请求 UAC。游戏高权限、未启动或无法判断时才提供手动授权，零安装 native Broker 随 App ZIP 携带并只注册固定动作；拒绝时恢复普通热键。
- 为 App 包、Launcher、清单和校验文件添加 GitHub Artifact Attestations；继续保留 Ed25519 清单与 SHA256 校验，并明确来源证明不会让无证书 UAC 显示可信发布者。
- 重构 GitHub Pages 首页，以更简洁的新用户路径呈现下载、三种通道、首次启动、权限说明、功能边界、隐私与文档入口。
- 收敛全局快捷键为每个启用动作每个生命周期一次 `RegisterHotKey`，保留 Tk-owned message window/dispatcher 修复，不再引入 hook、轮询或原始输入后端；权限探测仅查询可见 War Thunder 窗口的进程名和 elevation token。
- 将绿色版启动器拆出顶层 `launcher/` 开发期包，集中 manifest 验签投影、下载缓存、安装事务、启动隔离和 launcher metadata，同时保留 `launcher.pyw` 单文件分发入口。
- 拆出设置对话框的 headless 表单校验/保存 payload helper，并将主窗口贴边锚点几何逻辑下放为可单测 helper，降低 `dialogs.py`/`app.py` 的协调负担。
- 清理 SDD 迁移期间保留的旧兼容面：移除 config facade re-export、旧 app 包 marker、launcher 安装事务旧模块、GameLogic delegator wrapper，以及 `UISnapshot` 展示字符串/颜色字段。

### 修复
- 修复独立导航窗口的 X/Alt+F4 只隐藏窗口却不恢复集成导航模式的问题。
- 修复部署脚本在 `PYTHONPATH` 隔离环境下直接执行时无法导入本地 `bomana` 包的问题。
- 修复更新资产部署验证误扫旧版历史清单，导致新签名 release 被旧无签名 manifest 阻断的问题。
- 修复 GitHub Actions 部署未写入版本化清单的问题，并在远端已有同 SHA256 资产时复用文件以减少重复上传。
- 移除 GitHub Actions 直连腾讯云主机部署入口，将国内更新服务部署固定为本机执行，避免 GitHub runner 到腾讯云的低速链路在后续 session 中被重新使用。
