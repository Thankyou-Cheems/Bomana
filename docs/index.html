GET STARTED

三步开始，不需要额外游戏插件

启动器负责下载、签名校验和版本回退；Bomana 直接读取游戏已经提供的本地数据。

  1. 01

    下载启动器

    从 GitHub Release 获取通用启动器，无需安装 Python。

  2. 02

    选择功能通道

    完整功能选 Enhanced；不需要投弹估算可选 Standard；只计时选 Lite。

  3. 03

    进入战斗

    启动 War Thunder 并进入战斗，Bomana 会自动连接 localhost:8111。

WINDOWS PERMISSION, EXPLAINED

提权只给热键，不给整个应用

Bomana 先启用普通热键；如果确认游戏也以普通权限运行，就完全不提权。游戏未启动、权限未知或以管理员运行时，才显示可选授权按钮。

  • 只注册当前启用的 F1–F12 固定动作
  • 不使用键盘钩子、轮询或 Raw Input
  • 只查询可见游戏窗口的进程名与管理员状态，不读内存
  • 组件随 App 包携带，不安装服务、计划任务或额外程序
  • 拒绝授权时 App 继续运行，并恢复普通热键

能做什么，也明确不做什么

官方数据边界

运行时只访问 `/indicators`、`/state`、`/map_obj.json` 与 `/map_info.json`，不读内存、不注入、不改游戏文件。

可验证的更新

启动器先验证 Ed25519 清单与 SHA256；GitHub Actions 还为发布文件生成可独立验证的 Artifact Attestations。

透明的隐私说明

匿名统计字段、用途和禁用方式公开；热键 Broker 不联网、不记录按键内容，也不参与统计。

FAQ

第一次使用常见的问题

为什么显示 8111 不可用？

机库通常没有完整飞行数据。进入战斗后再试；也可在浏览器访问 http://localhost:8111 确认游戏本地数据页可用。

一定要授予管理员权限吗？

不需要。Bomana 默认使用普通热键，确认游戏普通运行时不会提示。只有高权限或无法判断时才提供可选按钮；项目没有商业证书，因此 UAC 会显示“未知发布者”，拒绝不会影响其他功能。

CCRP 是游戏内部真实弹道吗？

不是。它是基于公开静态参数和飞行状态的工程估算，适用弹型与误差会在界面中明确提示。

可以和其他 8111 工具一起使用吗？

通常可以。Bomana 只读游戏本地 HTTP 数据，不占用独占连接；全局热键请避免与游戏或其他工具重复。
