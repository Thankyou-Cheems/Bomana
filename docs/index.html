05 · LOCAL BRIDGE

Bridge 只连接浏览器与官方 8111

Bridge 是唯一需要在 Windows 本机运行的组件。它不拥有 Edition、界面或解算逻辑， 只提供固定的只读路由与用户选择的本地数据存储。

  • 默认只监听 127.0.0.1 的固定端口池
  • 只转发枚举的官方 8111 GET 路由，不做代理
  • 不读游戏内存、不注入、不模拟按键
  • 手机访问仅在用户主动配对的临时局域网会话中开放
  • 可从系统托盘查看版本、打开 Launcher 或退出

官方数据边界

游戏状态运行时只访问本机 8111 的 /indicators、/state、 /map_obj.json、/map_info.json、/map.img 与 /icons.ttf， 不读内存、不注入、不改游戏文件。

可验证的更新

App Web 使用内容哈希资源和原子激活；Bridge 发布清单绑定 SHA-256，GitHub Actions 另外生成 Sigstore bundle。

03

08 · FAQ

第一次使用常见的问题

为什么显示 8111 不可用？

机库通常没有完整飞行数据。进入战斗后再试；也可在浏览器访问 http://localhost:8111 确认游戏本地数据页可用。

一定要授予管理员权限吗？

不需要。Bridge 以普通用户权限运行，只监听本机端口；项目没有商业证书， Windows 可能显示“未知发布者”。

CCRP 是游戏内部真实弹道吗？

不是。超级爆弹版是独立订阅功能，只使用官方 8111 观测、用户配置和经审查的离线静态数据，并明确提示不可用状态。

可以和其他 8111 工具一起使用吗？

通常可以。Bridge 只读游戏本地 HTTP 数据，不占用独占连接。
