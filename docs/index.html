Flight tools

核心功能

Bomana 聚焦全真模式的重复飞行流程，把计时、导航和飞行风险提示放在一个透明覆盖界面里。

15

收益周期计时

自动识别出生、着陆、死亡和重启恢复，支持倒计时声音提示。

CC

CCRP 投弹估算

基于公开参数和弹道模型估算投弹距离、飞行时间和特殊减速伞参数。

HD

战区与 HUD 导航

Heading tape、CDI、目标方位和距离提示，姿态异常时自动降级。

FL

燃油与返航估算

展示燃油量、消耗率、低油警告，并估算返航所需燃油。

SP

IAS/Mach 超速提醒

按机型 flight model 匹配限速库，分级提示 safe、caution、warning 和 critical。

CK

出击检查清单

自定义起飞前项目，配合透明置顶窗口、点击穿透和多显示器定位。

Compliance boundary

合规边界

Bomana 只读取 War Thunder 官方暴露的本机 HTTP 数据，不读取内存、不注入代码、不修改游戏文件，也不显示敌方隐藏信息。

只使用官方 8111 数据

数据来自 `/indicators`、`/state`、`/map_obj.json` 和 `/map_info.json`。

不开启 ESP 类能力

HUD 叠加层用于自身导航参考，不在无标记模式显示敌方标记。

公开源码可审查

更新检查、匿名统计、签名校验和打包流程均可在仓库中查看。

Security and privacy

透明更新与隐私摘要

启动器更新依赖签名清单与 SHA256 校验；匿名统计只用于产品质量和真实活跃度判断。

签名发布

Release 中的 launcher manifest 和 app manifest 带 Ed25519 签名，客户端先验证清单再信任版本、文件名和 SHA256。

匿名统计

统计字段包含设备哈希、安装 ID、版本、通道和事件类型；不收集姓名、邮箱、War Thunder 账号、精确位置、文件列表或输入内容。

用户可控

隐私政策公开记录收集边界、用途、禁用方式和联系入口，源码中的遥测实现也可直接审查。

FAQ

常见问题

8111 端口不可用怎么办？

先启动 War Thunder 并进入战斗，再访问 http://localhost:8111 检查本地数据页。仍为空时重启游戏并重新进入战斗。

为什么 Lite 没有导航、燃油或投弹预测？

Lite 是仅保留核心计时器的极简通道；需要完整飞行辅助时请选择 Enhanced，需要常规导航和燃油但不需要 CCRP 时请选择 Standard。

CCRP 预测可以完全等同游戏内弹道吗？

不能。CCRP 是基于公开参数与物理模型的估算，地图、状态、风和游戏内部实现都会带来误差，可在设置中手动校准。
