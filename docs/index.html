01 · GET STARTED

三步开始，不需要额外游戏插件

可使用启动器完成签名校验和版本回退，也可直接下载内置 Python 的 Lite 绿色版。 Bomana 只读取游戏已经提供的本地数据。

  1. 01

    选择下载方式

    使用国内 CDN 启动器，或从 GitHub Release 下载 Lite 绿色版；两者都无需安装 Python。

  2. 02

    选择功能通道

    Standard / Lite 可直接使用；超级爆弹版会打开浏览器，通过 CheemsPay 完成订阅授权。

  3. 03

    进入战斗

    启动 War Thunder 并进入战斗，Bomana 会自动连接 localhost:8111。

05 · PERMISSION

系统热键只控制 Bomana

Bomana 以普通权限直接注册系统热键，不探测游戏进程，不会因为游戏状态自动请求 UAC。 若前台权限边界阻止热键，投弹栏、主窗与托盘仍提供等价按钮。

  • 默认 F6–F11，只触发 Bomana 固定动作
  • 不使用键盘钩子、轮询或 Raw Input
  • 不枚举或打开游戏进程，不查询游戏权限
  • 不向游戏合成按键，也不自动操作投放
  • 热键失效时不影响按钮、托盘与 8111 功能

06 · BOUNDARIES

能做什么，也明确不做什么

01

官方数据边界

游戏状态运行时只访问本机 8111 的 /indicators、/state、 /map_obj.json、/map_info.json、/map.img 与 /icons.ttf， 不读内存、不注入、不改游戏文件。

02

可验证的更新

启动器先验证 Ed25519 清单与 SHA256；GitHub Actions 还为发布文件生成可独立验证的 Artifact Attestations。

03

透明的隐私说明

匿名统计字段、用途和禁用方式公开；热键 Broker 不联网、不记录按键内容，也不参与统计。

08 · FAQ

第一次使用常见的问题

为什么显示 8111 不可用？

机库通常没有完整飞行数据。进入战斗后再试；也可在浏览器访问 http://localhost:8111 确认游戏本地数据页可用。

一定要授予管理员权限吗？

不需要。Bomana 默认使用普通热键，确认游戏普通运行时不会提示。 只有高权限或无法判断时才提供可选按钮；项目没有商业证书，因此 UAC 会显示“未知发布者”， 拒绝不会影响其他功能。

CCRP 是游戏内部真实弹道吗？

不是。超级爆弹版是独立订阅功能，只使用官方 8111 观测、用户配置和经审查的离线静态数据，并明确提示不可用状态。

可以和其他 8111 工具一起使用吗？

通常可以。Bomana 只读游戏本地 HTTP 数据，不占用独占连接； 全局热键请避免与游戏或其他工具重复。
