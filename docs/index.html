05 · LOCAL BRIDGE

Bridge 只负责把 ExtUI 交给网页

它是唯一需要在 Windows 本机运行的组件。Bridge 不负责 Edition 或武器解算， 只转发固定的只读数据，并保存你的本地设置。

  • 默认只监听 127.0.0.1 的固定端口池
  • 只检查 8111 / 9222 / 10333，并转发枚举的 ExtUI GET 路由
  • 不读游戏内存、不注入、不模拟按键
  • 手机访问仅在用户主动配对的临时局域网会话中开放
  • 系统托盘可打开 Launcher、连接手机、查看版本或退出

08 · FAQ

第一次使用常见的问题

为什么显示 ExtUI 不可用？

机库通常没有完整飞行数据。进入战斗后再试，并运行 Bridge 诊断； Bridge 会自动检查 8111、9222、10333。

一定要授予管理员权限吗？

不需要。Bridge 以普通用户权限运行，只监听本机端口；项目没有商业证书， Windows 可能显示“未知发布者”。

CCRP 是游戏内部真实弹道吗？

不是。Enhanced 只使用官方 ExtUI 观测、用户配置和离线静态数据，并会在条件不足时明确提示不可用。

可以和其他 8111 工具一起使用吗？

通常可以。Bridge 只读游戏本地 HTTP 数据，不占用独占连接。
